# NiceDocs

This extension adds documentation-writing skills, adapted from the Write the Docs
Documentation Guide, under `skills/`. When a task involves writing, reviewing, or
tooling software documentation, use the matching skill. If skills are not enabled in
this Gemini CLI, read its `SKILL.md` directly.

| Task | Skill |
|---|---|
| Audit or structure a doc set against documentation principles | `skills/docs-principles/SKILL.md` |
| Write a README, project docs, release notes, or an FAQ | `skills/project-docs/SKILL.md` |
| Review docs for style, accessibility, inclusive language, microcopy | `skills/docs-review/SKILL.md` |
| Write, fix, or convert Markdown / reStructuredText / AsciiDoc / XML | `skills/docs-markup/SKILL.md` |
| Docs-as-code, choosing tools, docs CI, SEO, API docs | `skills/docs-tooling/SKILL.md` |
| Justify docs, build a docs culture, support teams, imposter syndrome | `skills/docs-advocacy/SKILL.md` |

Load a skill's `references/` files only when the skill points you to them.
